# Landing page videos

Put five short clips here with **exactly these names**. The landing page plays them in this order,
muted and looping, and moves to the next one when a clip ends. A missing clip shows a coloured
panel with its caption instead.

| File | Scene |
|---|---|
| `01-kids-playing.mp4` | Kids happily playing with toys |
| `02-warehouse.mp4` | Warehouse with toys neatly arranged on labelled shelves |
| `03-quality-check.mp4` | Staff wearing gloves checking / scanning toys |
| `04-sanitation.mp4` | Toys being cleaned / sanitised |
| `05-delivery.mp4` | Delivery person handing a box to a happy customer |

Optional: a still image with the same name and `.jpg` (e.g. `01-kids-playing.jpg`) shows while the
video loads.

**Keep each clip small:** 8–12 seconds, 720p, H.264 MP4, under 4 MB, so the page loads fast on
mobile data. Pexels and Pixabay offer "SD"/"HD 720p" downloads.
